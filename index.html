🌾 AgriConnect

This is a demo page showing the Farm Assistant widget embedded, bottom-right.

Try the widget

Click the green leaf button in the bottom-right corner of this page. You can ask a farming question (e.g. "when should I plant maize"), or use the menu to list produce for sale or search for a seller.

Before you start

Make sure the backend is running locally first:

python train.py then uvicorn app:app --reload

See README.md for full setup steps and how to embed this widget on your own PHP site.
